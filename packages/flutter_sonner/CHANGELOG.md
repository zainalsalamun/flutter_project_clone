## 0.1.0

* Initial release of `flutter_sonner`.
* Stacked card animations with 3D depth, scaling, and opacity.
* Tap or hover to smoothly expand the toast stack.
* Horizontal swipe-to-dismiss support.
* Global context-free API (`Sonner.success()`, `Sonner.error()`, `Sonner.info()`, `Sonner.warning()`, `Sonner.loading()`).
* Native Future support via `Sonner.promise()`.
* Multiple placement positions (`topCenter`, `bottomCenter`, `bottomRight`, `topLeft`, etc.).
* Light and dark mode support with auto-detection.
* Optional subtle haptic feedback on dismiss and trigger.
* Customizable theme, durations, actions, and custom widgets.
